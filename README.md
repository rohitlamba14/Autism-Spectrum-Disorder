Autism Spectrum Disorder Detection in Toddlers

This repository contains the code and dataset used for Autism Spectrum Disorder (ASD) detection in toddlers using Machine Learning.

Dataset

The dataset used in this work is the Autism Screening Data for Toddlers available on Kaggle.

Kaggle Dataset:
https://www.kaggle.com/datasets/fabdelja/autism-screening-for-toddlers


Tools
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn
SHAP
Description

The notebooks contain the machine learning workflow for early ASD detection in toddlers, including data preprocessing, model training, evaluation, and explainability analysis.
